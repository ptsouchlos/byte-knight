# Failures

This folder contains PGN files of games where there was a crash or disconnect during a SPRT test. I save these to try and reproduce the issues and fix them. They can also potentially be used to create new tests of edge cases I hadn't previously considered. Below is a table of the failure file with links to the relevant SPRT test. The files are named as `YYYYMMDD_rnd<round number from failure>.pgn`. The date recorded is the datae of the failure as recorded in the uploaded PGN as well as the round number.
